# 🏮 初一庙会抽签 - 轻量 Roguelike

一款以中国传统春节庙会为背景的轻量肉鸽游戏。玩家选择生肖开局，在 12 节点的庙会地图上行走，每步遭遇随机事件，通过选择应对方式改变财、情、健、业四维运势，任一维度归零或满 100 即触发结局。

## ✨ 特性

- **生肖系统**：12 生肖各有不同初始运势加成
- **随机事件**：红包、口舌、贵人、破财等多种事件类型
- **策略选择**：每个事件 2-3 个选项，不同选择改变运势走向
- **四维运势**：财、情、健、业，任一维度归零或满值触发结局
- **种子系统**：支持分享种子复现同一局游戏
- **12 节点地图**：Canvas 渲染的环形庙会地图
- **本地存储**：记录最佳结局与游戏统计
- **响应式设计**：支持桌面端和移动端

## 🎮 玩法说明

1. 选择你的生肖开始游戏
2. 可选输入种子复现对局
3. 点击「往前走」移动到下一个节点
4. 遇到事件后选择应对方式
5. 观察运势变化，策略规划选择
6. 任一维度归零/满值，或走完 12 节点，触发结局
7. 查看结局文案，分享种子给朋友

## 🛠️ 技术栈

- **前端框架**：React 18 + TypeScript
- **构建工具**：Vite
- **样式方案**：TailwindCSS 3
- **状态管理**：Zustand
- **渲染方案**：原生 HTML5 Canvas API
- **数据存储**：localStorage
- **容器化**：Docker + nginx

## 🧪 5 个必测事件分支

### 测试 1：红包事件 - 财运上涨路径

**事件**：🧧 天降红包（redpacket_1）

**选择 1**：恭敬接过，道谢离开
- 效果：财运 +12
- 预期：运势面板财运值增加 12

**选择 2**：推辞一番，再收下
- 效果：财运 +8，情运 +5
- 预期：财运和情运均有提升

**选择 3**：坚决不收，转身就走
- 效果：业运 +10
- 预期：事业运势显著提升

### 测试 2：口舌事件 - 运势下降路径

**事件**：😤 口角之争（quarrel_1）

**选择 1**：据理力争，讨个说法
- 效果：业运 +8，健运 -10
- 预期：事业上升但健康下降

**选择 2**：忍一时风平浪静
- 效果：健运 +5，情运 +5
- 预期：健康和感情均有提升

**选择 3**：直接走人，懒得计较
- 效果：财运 -5，业运 +3
- 预期：财运小幅下降，事业小幅上升

### 测试 3：贵人事件 - 三维选择分支

**事件**：👴 贵人相助（noble_1）

**选择 1**：虚心求教，洗耳恭听
- 效果：业运 +15
- 预期：事业运势大幅提升

**选择 2**：请教健康养生之道
- 效果：健运 +15
- 预期：健康运势大幅提升

**选择 3**：询问姻缘感情
- 效果：情运 +15
- 预期：感情运势大幅提升

### 测试 4：破财事件 - 止损智慧

**事件**：💸 破财消灾（losemoney_1）

**选择 1**：赶紧回去找
- 效果：财运 -15，健运 -5
- 预期：财运和健康均下降

**选择 2**：破财消灾，算了
- 效果：财运 -10，健运 +5
- 预期：财运下降但心态平和健康上升

**选择 3**：报警处理
- 效果：财运 -8，业运 +8
- 预期：财运下降但事业（责任感）上升

### 测试 5：结局触发 - 峰值与谷值

**测试目标**：验证运势满值/归零触发对应结局

**巅峰结局测试**：
- 操作：连续选择增益选项，使某一维度达到 100
- 预期：触发对应维度的巅峰结局（如财运满值 → 「财运亨通」结局）

**低谷结局测试**：
- 操作：连续选择减益选项，使某一维度降至 0
- 预期：触发对应维度的低谷结局（如财运归零 → 「一贫如洗」结局）

**平安结局测试**：
- 操作：平稳选择，使所有维度保持在 0-100 之间，走完 12 节点
- 预期：触发「平安顺遂」普通结局

## 🔍 种子复现验证

使用相同种子 + 相同生肖 + 相同选择顺序，应得到完全相同的游戏体验：

1. 记录一局游戏的种子值
2. 重新开始，输入相同种子和生肖
3. 按相同顺序选择选项
4. 验证每一步事件和运势变化完全一致

## ✅ 行囊与摊铺系统验收标准

### 验收 1：同种子摊铺位置一致

**测试目标**：验证相同种子生成的摊铺位置和商品完全相同

**测试步骤**：
1. 记录一局游戏的种子值，观察哪些节点是摊铺（红色 🏮 节点）
2. 重新开始，输入相同种子和生肖
3. 验证摊铺节点位置与上一局完全相同
4. 进入摊铺，验证商品种类、价格、库存与上一局完全一致

### 验收 2：财运不足无法购买

**测试目标**：验证财运不足时购买按钮置灰且无法购买

**测试步骤**：
1. 进入摊铺节点，查看商品价格
2. 选择一个价格高于当前财运的商品
3. 验证购买按钮显示「财运不足」且为灰色置灰状态
4. 点击按钮验证无法购买，且有「还差 X 财运」的提示
5. 选择一个价格低于当前财运的商品，验证可以正常购买

### 验收 3：护身符对负向选项生效

**测试目标**：验证护身符道具能使本次选项负面效果减半

**测试步骤**：
1. 确保行囊中有护身符道具（🧿）
2. 触发一个带有负面效果的事件（如口舌、破财类）
3. 在事件抉择前，点击行囊中的护身符使用
4. 选择带有负面效果的选项
5. 验证负面效果值为原值的一半（向下取整），例如 -10 变为 -5
